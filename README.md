## `featured_projects`

### 1. [`ani-mobile`](https://github.com/NonLaHu/ani_mobile)
`Flutter` · `Dart` · `media_kit` · `libmpv` · `MIT License`

An open-source anime streaming and offline downloading application built entirely with **Flutter** and **Dart**.

- **Native Playback Engine:** Powered by `media_kit` and native `libmpv` for hardware-accelerated **HLS** (`.m3u8`) streaming with subtitle and sub/dub audio-track handling.
- **Resilient Networking:** Dynamic HTTP header injection (`Referer`, `User-Agent`, `Origin`) across both `Dio` requests and `media_kit` streams, paired with automatic source and quality fallback recovery.
- **On-Device Architecture:** Modular on-device HTML scraping (`Riverpod` state management), offline episode downloads, and local watch-history persistence.


### 2. [`Digital Studio`](https://github.com/NonLaHu/clayPotThreeDemo)
`Three.js` · `MediaPipe Tasks Vision` · `WebGL` · `Vite` · `Docker`

An interactive 3D pottery and digital craft studio built with **Three.js** and **MediaPipe** 21-point hand landmark tracking, containerized with Docker and Nginx.

- **Three-Room Pipeline (`Sculpt → Paint → Draw`):** Driven by prioritized webcam hand gestures (index pointing, pinch radius deformation, two-finger height stretch, open-palm camera orbit, and timed thumbs-up room transitions) with mouse fallback and Web Audio synthesis.
- **Vertex, Color & Pattern Engines:** Real-time vertex deformation on a `THREE.LatheGeometry` mesh, a hand-angle sunflower color selector with per-vertex gradient ring painting, and a `2048×2048` canvas pattern stamping engine with rotary selection and undo history.
- **Measurement, QR Sharing & 3D Export:** Live physical dimension readouts (`cm` / `in`), printable exhibition posters, local booth persistence (`/api/saves`) with QR save/restore, a standalone `/s/:id` 3D viewer, and binary **GLB** export via `GLTFExporter`.


### 3. [`audvis`](https://github.com/NonLaHu/audvis)
`JavaScript` · `Web Audio API` · `HTML5 Canvas 2D` · `MediaRecorder` · `MIT License`

A local-first, zero-dependency browser audio visualizer and soundwave video generator — 100% client-side with no backend, build step, or file uploads.

- **18 Reactive Visualizer Engines:** Organized across five categories (`Bars`, `Waves`, `Radial`, `Geometric`, `Cosmic`) with real-time FFT (`32`–`4096`), smoothing, geometry, glow, 7 color modes, and custom center artwork.
- **Multi-Source Audio Engine:** Supports local audio files (`MP3`, `WAV`, `AAC`, `OGG`, `FLAC`, `M4A`, `WebM`), live microphone capture (`getUserMedia`), and a built-in `118 BPM` procedural Demo Synth.
- **Offscreen Video Export:** Records scaled (`1×`–`3×`, `30`/`60 fps`) **WebM (`VP9`)** with alpha transparency and **MP4** via `MediaRecorder`, including a custom inline **EBML binary duration patcher** (`webm-duration.js`) that writes `Segment > Info > Duration` metadata for accurate scrubbing.
